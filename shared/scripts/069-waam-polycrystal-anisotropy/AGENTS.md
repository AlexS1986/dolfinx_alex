## This folder = the FE stage
Per-grain anisotropic linear elasticity on the Neper meshes. Runs in the
**dolfinx v0.7.3** container (`alex-dolfinx`): `shared/ -> /home`,
`PYTHONPATH=/home/utils`, so this is `/home/scripts/069-waam-polycrystal-anisotropy`.
The Neper folder is NOT mounted here — meshes arrive via `inputs/` (see
`prepare_inputs.py`, run on the host).

## Files
- `waam_crystal.py` — shared core: read mesh + `grain` tags + `grain_ori`, build
  per-cell DG0 rotated cubic stiffness (6x6 Bond), anisotropic stress/energy/avg.
- `homogenize_rve.py` — KUBC (6 macro-strains) -> `Chom_<tag>.json`.
- `uniaxial_tension.py` — symmetric-BC uniaxial test -> `Emodul_<tag>.json`.
- `config.json` — single-crystal C11/C12/C44 per phase (**placeholders, edit**).
- `run_fem.sh` — run all cases. `evaluation.py` — figures + summary. `report/`.
- `prepare_inputs.py` — host-side mesh staging into `inputs/`.

## Hard rules
- **dolfinx v0.7.3 API only** (`ufl.VectorElement/TensorElement` +
  `dlfx.fem.FunctionSpace`). Mirror `009-.../00_template/linearelastic.py`.
- **Never edit the shared `alex` package**; add helpers here instead.
- Voigt order `[xx,yy,zz,yz,xz,xy]`, engineering shear (matches `alex`).
- Cannot run dolfinx in the agent sandbox — only `py_compile` / numpy checks.
  The Bond-rotation math must stay verified (random-orientation average → isotropic).
- Read grains with `read_mesh(name="Grid")` + `read_meshtags(name="Grid")`.
- Results in GPa, scale with `config.json` — flag placeholders in any report.

## Verify
`python3 -m py_compile *.py`; `bash -n run_fem.sh`; check `waam_crystal`
numpy helpers standalone (cubic invariance, isotropic aggregate).

## Report policy
The scientific report (`report/report.md` → `WAAM_anisotropy_report.docx`, rebuilt
via `pandoc report.md -o WAAM_anisotropy_report.docx`) is the single source of
explanations. **When the user asks a comprehension question about a concept in
the report, add/clarify it IN the report** (not only in chat), rebuild the docx,
and re-sync the deposited snapshot under
`Publications/02_WAAM_N1_Mikrostruktur/waam_elastic_anisotropy/report/`. All
report figures are generated by `evaluation.py` (add new ones there).
