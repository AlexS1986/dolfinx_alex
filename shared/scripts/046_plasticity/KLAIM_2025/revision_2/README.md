Bibliography is inline (`thebibliography` in the tex), so no bibtex run is needed. Quote kinds for `%@quote`:
`cmd:<text>` (a markup command containing the text; add `@n` to pick the n-th), `cmdall:<text>`, `env:<label>` (a
displayed equation — use this for math changes, a bare `cmd:` quote of a math fragment does not compile).
