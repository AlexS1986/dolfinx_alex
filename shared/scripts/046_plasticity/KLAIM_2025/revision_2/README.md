## Build (TeX Live with `changes`, `ulem`, `pgfplots`; the Mac's TeX works, the cloud build used TeX Live 2023)

```bash
cd revision_2
pdflatex manuscript_revised_template.tex && pdflatex manuscript_revised_template.tex      # marked (30 pages at the moment)
python3 make_clean_manuscript.py manuscript_revised_template.tex manuscript_revised_clean.tex
pdflatex manuscript_revised_clean.tex && pdflatex manuscript_revised_clean.tex            # clean
python3 build_response_quotes.py manuscript_revised_template.tex manuscript_revised_template.aux response_to_reviewers_template.tex
pdflatex response_to_reviewers_template.tex && pdflatex response_to_reviewers_template.tex
pdflatex response_to_editor_template.tex
```
Bibliography is inline (`thebibliography` in the tex), so no bibtex run is needed. Quote kinds for `%@quote`:
`cmd:<text>` (a markup command containing the text; add `@n` to pick the n-th), `cmdall:<text>`, `env:<label>` (a
displayed equation — use this for math changes, a bare `cmd:` quote of a math fragment does not compile).

## Rules

* Edit only `manuscript_revised_template.tex` and the letter/cover-letter templates; regenerate the clean file and the
  quotes after every change. The clean letter must contain no `\mycomment`, the clean manuscript no "Revision Working Note".
* `\replaced{new}{old}` — new text first (changes-package convention; the v2.0 file used a private macro with the
  opposite order, which is why the baseline was generated by accepting the round-1 markup first).
* Equation changes: `\changed{...}` inside the equation and `%@quote env:<label>` in the letter.
