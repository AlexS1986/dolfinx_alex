### Graph-table format (`run_simulation_graphs.txt`, whitespace separated, 1 comment line)

| Columns | 2D vM (046, 062; 14 cols) | 2D elastic (045, 049; 12 cols) | 3D vM (061; 12 cols) |
|---|---|---|---|
| 0 | t (pseudo-time, L/ẋ_bc) | t | t |
| 1,2 | J_x, J_y | J_x, J_y | J_x, J_y |
| 3 | x_ct (crack tip, max x with s=0) | x_ct | J_z |
| 4 | x_bc (surfing-BC tip) | x_bc | x_ct |
| 5,6 | R_x, R_y (top boundary) | R_x, R_y | x_bc |
| 7,8 | dW, W (external work) | dW, W | R_x, R_y |
| 9 | A (regularized crack surface, incl. initial crack) | A | R_z |
| 10 | dt | dt | dW |
| 11 | E_el | E_el | W |
| 12 | E_total (= E_el + E_pl exactly) | – | A |
| 13 | E_pl = ∫ g(s)(½Hα²+σ_yα) (degraded, stored form) | – | – |

Energy-balance check on existing vM data: W ≠ E_el + E_pl + J_c·A — the gap (≈4–8 J_c^0 L) is plastic work that
was dissipated in zones later degraded (g→η), viscous dissipation of the Allen–Cahn mobility, and the initial
crack contained in A. Undegraded cumulative plastic dissipation and viscous dissipation are **not** recorded.

`parameters.txt` per run: `lam_effective`, `mue_effective` (from the unit-cell homogenization),
`nholes, dhole, wsteg, e0, e1`, mesh statistics, then the simulation record (`Gc_simulation, eps, eta, mob,
in_crack_length`). The **full effective stiffness matrix is NOT stored** — it is only printed to stdout
(`[[C11 C12 0],[C12 C22 0],[0 0 C33]]`, then "Lam Hom/Mu Hom/E Hom/Nu Hom") → lives in SLURM `wsteg_job.out.<id>`
files on the cluster. `lam_eff = C12`, `mu_eff = C33`; **C11 is discarded**, i.e. isotropy is assumed, not checked.
(In 2D all porous runs happen to give lam_eff ≈ mu_eff; 3D: lam_eff=0.853, mu_eff=0.890 for w_s=1.)

## 6. Model facts and numbers used in the paper (for consistency checks)

* Parameter sets: [vM]: σ_y = 1.0 √(J_c^0 µ0/L), H = 0.22 µ0, λ = µ0, J_c = J_c^0. [Eq J_c]: elastic, J_c = J_c^0.
  [Eq σ*]: elastic, J_c = 0.5679 J_c^0 (same 1D fracture stress as vM).
* Homogeneous strip: J_c^num ≈ 1.50 (vM), 1.12 (Eq J_c), 0.64 (Eq σ*) in units of J_c^0.
* 1D bar: σ* = 1.31 σ_y (vM), 1.72 (Eq J_c), 1.30 (Eq σ*); ε* = 1.18, 1.08, 0.82 √(J_c^0/(µ0 L));
  Π* = 2.16, 2.22, 1.29 J_c^0 L.
* 2D saturation of J_x,c^eff: ≈1.80 J_c^num (vM), 1.9 (Eq J_c), 1.12 (Eq σ*) [all normalized by 1.12 J_c^0];
  for w_s ≤ 0.6 L vM is below Eq σ*. 3D vM saturation ≈1.15 J_c^{num,pl} vs 1.25 in 2D.
* Scaling fact (useful for R3-C3): for the rate-independent linear-elastic model J_x,c^eff ∝ J_c exactly
  (dimensional analysis); the data confirm it: 1.9×1.12/1.0 ≈ 1.12×1.12/0.5679 ≈ 2.1–2.2 J_c in units of the
  *own* J_c → Eq J_c and Eq σ* are the same curve up to the factor J_c.

### Discrepancies found between code and manuscript (verify before resubmission)
1. **Degradation function β:** manuscript says β = 0.2. Code: `pf.cubic_degradation(beta=0.1)` is the default and
   the (now commented-out) legacy `degrad_cubic` also had `beta=0.1`. The 2D porous vM (046), 2D elastic (045),
   3D (061) and strip (062) runs use `pf.degrad_cubic` → most likely **β = 0.1**. Only 048 (`cubic_degradation(0.2)`)
   and the 1D bar 050 (`cubic_degradation(beta=0.2)`) used 0.2. The live `shared/utils/alex/phasefield.py` (May 2026) has
   **no** `degrad_cubic` any more (only `cubic_degradation(beta=0.1)`), so the old templates would not even run today; the
   noll class needs `.derivative`, hence the cluster version must have been `degrad_cubic = cubic_degradation()` → β = 0.1.
   **Decision 2026-10-15: all reruns use β = 0.2 explicitly** (`pf.cubic_degradation(beta=0.2)`), consistent with the
   manuscript and the 1-D bar.
2. **η in 3D:** `061` uses `eta = 0.001`; manuscript states η = 10⁻⁵ for 3D. Reruns (076) use 1e-5 (CLI `--eta`).
3. dolfinx version: manuscript 0.7.4, research-data README verified 0.7.3 → corrected in `revision_2/` (marked).
4. `postprocessing_interval` differs (400 vs 200 vs 20) — irrelevant for tables, relevant for field snapshots.
5. **Surfing-BC parameters:** manuscript states E_bc = 2.5 µ0, ν_bc = 0.25 (→ µ_bc = µ0) and K_I^bc = √(2.5 J_c^0 µ0).
   The code (`compute_surf_displacement`) uses `K1 = sqrt(2.5)` but divides by the **cell-wise `mu`** (= µ_eff on the
   outer boundary, 0.50–0.95 depending on w_s) and uses `nu` from (λ_eff, µ_eff) (= 0.25 since λ_eff ≈ µ_eff).
   So effectively E_bc = E_eff(w_s), not 2.5 µ0. J_x is measured, so J_x,c^eff is unaffected in its definition. Same
   pattern in 045/061/062. **Final decision (user, 2026-10-15, after one back-and-forth): keep the effective moduli**
   (`--bc_moduli effective`, default in 075/076 — physically the K-field of the embedding medium and continuity with
   the v2.0 runs) **and the manuscript was corrected** (Secs. 4.2, 5.1: E_bc = E_0^eff, ν_bc = ν_0^eff; Sec. 3.5 strip is
   homogeneous, so E_bc = 2.5µ0, ν = 0.25 stays correct there). `--bc_moduli fixed` + `--E_bc/--nu_bc` remain available.
   Eq. (2): κ = 3 − 4ν (plane strain). All four corrections are marked in `revision_2/manuscript_revised_template.tex` and
   listed in the letter section "Additional corrections by the authors" (`revision_2/manuscript_corrections_from_code_audit.md`).
6. **Crack surface density (factor 2):** manuscript ψ_fr = J_c[(1−s)²/(2ε) + 2ε|∇s|²]; code (`alex.phasefield.surf`,
   `psisurf_from_function`) uses the standard J_c[(1−s)²/(4ε) + ε|∇s|²] (integrates to J_c per unit crack length).
   The manuscript's own evolution equation (19) `−J_c(2εΔs + (1−s)/(2ε))` and σ_c formula (26) are consistent with the
   **code** form, so eq. (18) in the manuscript was off by a factor 2 → corrected in `revision_2/manuscript_revised_template.tex` (marked, quoted in the letter).
8. **Yield stress in the embedding:** old scripts use one global σ_y, so the "linear elastic" embedding could yield in
   principle (stress concentrations are inside the porous block, so probably irrelevant). Reruns: σ_y = 1e6 in the
   embedding (`--sig_y_embedding`), i.e. linear elastic as the manuscript says.
9. **Energy balance of the model (exact):** W_ext = E_el + E_pl(stored, degraded) + E_frac + D_visc with
   D_visc = ∫∫ ṡ²/M (derivation: dE/dt with the evolution equation; plastic work is entirely "stored" in g(s)ψ_pl).
   The unrecorded residual of the old tables is therefore the viscous dissipation of unstable crack jumps.
10. **2D homogenization bug (found 2026-10-15 in the first cluster test):** `alex.boundaryconditions.
    get_total_linear_displacement_boundary_condition_at_box` also applies the front/back conditions z = z_min/z_max;
    in a 2D mesh z = 0 everywhere, so the affine displacement was prescribed on *all* exterior facets incl. the pore
    surface → affine solution → ⟨σ⟩ = (1 − f)·C_bulk exactly (Voigt bound, isotropic, Zener = 1). All 2D paper runs
    (044/045/046) used this embedding stiffness (λ_eff = µ_eff = 0.8037 = 1 − π/16 at w_s = 1). 3D (061) and the
    homogeneous strip are not affected. Fixed in `075_klaim_rev2_2D/000_template/run_effective_stiffness.py` (outer
